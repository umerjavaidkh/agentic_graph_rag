Settings

Tuning dials for ingestion, models and graph construction.

Changes apply on restart. Settings are read once when a process starts, so saving stores the value — it does not change a running worker. Restart with docker compose up -d, which is also what WORKER_REPLICAS needs in order to change the number of containers.

Only tuning settings appear here. Credentials and the safety switches (ALLOW_CYPHER_INGEST, ALLOW_DB_RESET) are deliberately not editable from a web page.
