CYPHER SYNTAX:
- Cypher does NOT support SQL GROUP BY. Use WITH to aggregate and group
- Do NOT use SQL window functions: ROW_NUMBER() OVER, RANK() OVER,

- Every expression in WITH must be aliased with AS
- Never nest MATCH inside RETURN. Use multiple WITH stages, or return
  aggregated maps/lists only
- Alias results after what they actually measure. Never label one property as
  a different concept

- Use COUNT(DISTINCT node) when counting entities that repeat across joins
- Aggregations and rankings ("most", "highest", "top"): MATCH the full path,

- Duration argument order: duration.inDays(earlier, later) and
